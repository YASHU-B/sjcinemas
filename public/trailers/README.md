# Raw Trailers Directory for SJ Cinemas Nagari Simulator

Drop your raw movie trailer video files into this directory (`public/trailers/`).
The simulator will automatically detect and stream raw video files in native 4K/1080p directly onto the curved Harkness cinema screen in 3D with synchronized Dolby Atmos audio!

### Supported Video Formats:
- `.mp4` (H.264 / AAC — recommended for universal browser compatibility)
- `.webm` (VP9 / Opus)

### Pre-configured File Names:
You can name your files matching any of the built-in trailer slots:
- `leo.mp4` — **Leo** (Thalapathy Vijay • Lokesh Kanagaraj • Anirudh)
- `coolie.mp4` — **Coolie** (Superstar Rajinikanth • Lokesh Kanagaraj • Anirudh)
- `goat.mp4` — **The Greatest of All Time (GOAT)** (Thalapathy Vijay • Venkat Prabhu • Yuvan Shankar Raja)
- `amaran.mp4` — **Amaran** (Sivakarthikeyan • Sai Pallavi • GV Prakash)
- `vikram.mp4` — **Vikram** (Kamal Haasan • Vijay Sethupathi • Fahadh Faasil • Anirudh)
- `jailer.mp4` — **Jailer** (Superstar Rajinikanth • Nelson • Anirudh)
- `pushpa2.mp4` — **Pushpa 2: The Rule** (Allu Arjun • DSP)

You can also load any local raw video file on the fly using the **"Load Raw Video"** button or by dragging and dropping an `.mp4` file directly into the simulator!
